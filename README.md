# allowance-ledger

A simple web-based mobile-friendly allowance tracker for Quinn and Logan.

## Features

- Separate balances for Quinn and Logan
- Automatic weekly allowance credits based on each child's configured weekly amount
- Manual credits and debts with timestamps
- Debt list plus a full activity ledger for each child
- Responsive layout tuned for iPhone-sized screens

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.

## Test

```bash
npm test
```
